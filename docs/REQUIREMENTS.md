## 一、项目定位

CLI 工具管理器是一个**通用的命令行工具管理平台**，用于统一发现、安装、更新、配置和卸载系统中所有的 CLI 工具。它类似于"CLI 工具的仪表盘+管家"，让用户能够一站式管理系统中散落在各处的命令行工具。

### 核心能力

| 能力 | 说明 |
|------|------|
| **发现** | 自动扫描系统中已安装的所有 CLI 工具 |
| **管理** | 查看工具信息、分类、版本、路径 |
| **安装** | 从多种来源安装新工具（npm/pip/GitHub/scoop/winget） |
| **更新** | 检查更新、批量更新、版本锁定 |
| **卸载** | 干净卸载工具并清理残留 |
| **诊断** | PATH 检测、环境健康检查、冲突检测 |

## 三、🔴 P0 — 核心基础设施（必须最先完成）

### P0-1 工具发现与扫描引擎

| ID | 需求名 | 描述 | 验收标准 |
|----|--------|------|----------|
| REQ-P0-01 | PATH 目录遍历 | 读取系统 PATH 环境变量，遍历所有目录中的可执行文件 | 能列出 PATH 中所有目录及文件数 |
| REQ-P0-02 | 可执行文件识别 | 识别 `.exe`、`.ps1`、`.cmd`、`.bat`、无扩展名等可执行文件 | 正确分类各类型可执行文件 |
| REQ-P0-03 | 版本号自动提取 | 对每个工具执行 `--version` / `-v` / `version` 提取版本号 | 80% 以上工具能正确提取版本 |
| REQ-P0-04 | 元数据采集 | 提取文件大小、数字签名、修改时间、所属包管理器 | 每个工具记录 6+ 元数据字段 |
| REQ-P0-05 | npm 全局包发现 | 扫描 `npm root -g` 目录，识别 npm 安装的 CLI 工具 | 准确列出所有 npm 全局包 |
| REQ-P0-06 | pip 包发现 | 解析 `pip list` 输出，识别 Python 安装的 CLI 工具 | 准确列出所有 pip 包入口 |
| REQ-P0-07 | 工具去重与优先级 | 同名工具按 PATH 顺序排序，标记优先级 | 同名工具正确排序，无重复项 |
| REQ-P0-08 | 工具来源分类 | 自动判断工具来源（system/npm/pip/scoop/manual） | 分类准确率 > 90% |

### P0-2 工具清单数据库

| ID | 需求名 | 描述 | 验收标准 |
|----|--------|------|----------|
| REQ-P0-09 | 工具信息数据模型 | 定义工具信息的结构化模型（名称、路径、版本、来源等） | 数据模型覆盖 10+ 字段 |
| REQ-P0-10 | 本地持久化存储 | 使用 JSON/SQLite 存储工具清单，支持读写 | 数据可持久化、可恢复 |
| REQ-P0-11 | 增量扫描与快照 | 支持全量扫描和增量更新，对比快照识别变更 | 新增/移除/变更工具正确标记 |

## 六、🔵 P3 — 版本管理与更新

| ID | 需求名 | 描述 | 验收标准 |
|----|--------|------|----------|
| REQ-P3-01 | `version <name>` — 查看版本 | 显示当前版本和所有可用版本 | 版本信息准确 |
| REQ-P3-02 | `use <name> <version>` — 切换版本 | 多版本切换（类似 nvm use） | 切换后 `--version` 正确 |
| REQ-P3-03 | `pin <name> <version>` — 锁定版本 | 锁定工具版本防止被更新 | 锁定的工具在批量更新中被跳过 |
| REQ-P3-04 | `unpin <name>` — 解锁版本 | 解除版本锁定 | 解锁后可正常更新 |
| REQ-P3-05 | `list-versions <name>` — 可用版本 | 列出该工具所有可用版本 | 版本列表完整 |
| REQ-P3-06 | `update <name>` — 更新单个 | 将指定工具更新到最新版 | 更新后版本号正确 |
| REQ-P3-07 | `update all` — 批量更新 | 更新所有未锁定的工具 | 批量更新成功，锁定版本跳过 |
| REQ-P3-08 | `rollback <name>` — 版本回退 | 回退到上一个稳定版本 | 回退后版本正确 |
| REQ-P3-09 | `history <name>` — 版本历史 | 查看版本变更记录 | 历史记录完整可追溯 |
